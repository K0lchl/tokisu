# Buddy Tracker (Location Info) 進捗と今後の予定

## 🚀 現在の進捗・実装済みの機能 (2026-05-18)

1. **永続的なペアリングと自動再接続**
   - `sessionStorage` から `localStorage` へ移行。
   - 初回ペアリング後、お互いのIDをブラウザに永続的に記憶。次回以降はページを開くだけで自動的に再接続する仕組みを構築。
   - 相手が一時的にオフラインになってもエラーで画面を戻さず、裏側で5秒間隔の自動再接続（リトライ）を行うように改善。

2. **バッテリー監視機能の削除**
   - iOS (Safari) のプライバシー制限により機能しないため、関連するUIおよび通信ロジックを完全に削除し、位置情報に特化。

3. **ルート選択 ＆ ARナビゲーション機能の実装**
   - 徒歩・車・公共交通機関の移動手段を選択可能に。
   - **アプリ内ARモード**: スマホのカメラとコンパスを利用し、現実の風景上に相手のいる方向（矢印⬆️）と残り距離をARでオーバーレイ表示。
   - **Google Maps連携**: 選択した移動手段を引き継いでネイティブのGoogle Mapsアプリを起動し、道に沿った最適なルートを案内。

4. **ペアリングの手動解除**
   - 別の相手と繋ぎ直したい場合のために、「ペアリングを解除して戻る」ボタンを設置して記憶のリセット機能を実装。

## 📝 今後する予定の作業・追加機能のアイデア

- [ ] **遠隔アラーム（音を鳴らす）機能**
  - 相手のスマホを置き忘れた際などに、こちらの画面から遠隔操作で相手のスマホからアラーム音を鳴らす。
- [ ] **バックグラウンド動作とプッシュ通知 (PWA化)**
  - Service Worker を導入し、画面を閉じている状態でも定期的に位置を共有・通知（置き忘れ通知など）を受け取れるようにする。
- [ ] **移動履歴（足跡・軌跡）の描画**
  - 現在地だけでなく、どのルートを通ってきたかを地図上に線で表示する。
- [ ] **ジオフェンシング（セーフゾーン設定）**
  - マップ上で特定のエリア（自宅や学校など）を設定し、そこから「出た」「入った」タイミングで自動通知を送る。
- [ ] **複数人（グループ）トラッキング対応**
  - 1対1だけでなく、家族やイベント用として複数人の現在地を同時にマップ上で確認できるように拡張。
